  # Crux CMS

  **A flexible, self-hosted headless CMS built on Next.js, SQLite/Turso, and TypeScript.**
  No cloud lock-in. No per-seat pricing. Runs anywhere Node.js runs.

</div>

---

Crux CMS gives developers a fast, flexible editorial UI and a clean REST API,
installed as a normal npm dependency into your own Next.js app. You own the
database and the config — entry types, fields, roles, and filesystem settings
live as plain JSON files that travel with your codebase.

- **Structured content** — entry types with typed fields, not freeform blobs
- **SQLite first** — a single local file, or [Turso](https://turso.tech) for distributed/edge deployments
- **Role-based permissions**, **passkey auth**, **webhooks**, **on-the-fly image transforms**
- **AI-assisted** alt text, captions, and content generation (optional, bring your own key)
